# chi2analysis

`chi2analysis` est un package R développé dans le cadre d'un exposé universitaire sur **La loi du Chi-Deux**. Il regroupe des fonctions utilitaires pour automatiser les tests d'ajustement, d'indépendance et explorer les simulations de cette loi de probabilité.
